# Agentic AI Learning Journey

This repository documents my hands-on learning journey in Agentic AI, LLM applications, and AI agents. It contains a series of Python-based demos and mini-projects that explore how large language models can be connected to tools, memory, workflows, search, and user interfaces.

## What I have learned so far

I have learned how to:
- Work with LLM APIs from providers such as Groq and Google Gemini
- Use prompt engineering to guide model behavior and output formatting
- Build simple AI apps that generate text, answer questions, and summarize content
- Create agent-based systems that can use tools such as web search and external APIs
- Build retrieval-augmented generation (RAG) systems using document indexing and semantic search
- Connect LLMs with workflow orchestration using LangChain and LangGraph
- Add observability and tracing with LangSmith and Langfuse
- Create interactive interfaces with Streamlit and Gradio
- Explore agent frameworks such as Google ADK, AutoGen, and MCP-based tools

## Tools and technologies used

The projects in this repository use a mix of modern AI and Python tools, including:
- Python
- dotenv for environment management
- Groq and Google GenAI APIs
- LangChain
- LangGraph
- LlamaIndex
- Streamlit
- Gradio
- AutoGen
- Google Agent Development Kit (ADK)
- Model Context Protocol (MCP)
- Cohere
- DuckDuckGo Search
- PyPDF and PDF document processing
- LangSmith and Langfuse for tracing and monitoring

## Systems and projects created

### 1. Basic LLM demos
I created simple examples that connect to LLM providers and generate content such as stories and short explanations.

### 2. Search-powered research assistant
I built agents that use web search tools to answer questions and write research-style reports.

### 3. Resume screening assistant
I created a system that extracts text from PDF resumes, analyzes them against job requirements, and produces a suitability score.

### 4. Financial advisor chatbot
I built a conversational finance assistant using LangGraph with state management, intent detection, profile extraction, and a human-in-the-loop checkpoint for high-risk queries.

### 5. RAG-based document assistant
I created document-based Q&A systems using LlamaIndex with stored indexes over PDF files such as Lyft and Uber reports.

### 6. Market research agent
I built a web-connected research app using Cohere and Gradio for user-friendly market analysis.

### 7. Travel concierge agent
I created a live travel assistance agent using Google ADK that can fetch real-time city facts and weather information from external APIs.

### 8. GitHub assistant with MCP
I explored an MCP-based GitHub assistant that connects an agent to GitHub tools through a Model Context Protocol server.

### 9. Interactive Streamlit apps
I created several Streamlit-based interfaces for AI chat, research workflows, and observability-driven resume screening.
